# 🚀 Challenge GitOps & Kubernetes Troubleshooting

Repositorio oficial para el desafío técnico de arquitectura, despliegue continuo con **ArgoCD** y simulación de escenarios de fallo (troubleshooting) en entornos **Kubernetes** locales (Minikube).

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Orquestador:** Kubernetes (Minikube / Docker Driver)
* **GitOps Continuous Delivery:** ArgoCD
* **Control de Versiones:** Git & GitHub
* **Contenedores:** Docker
